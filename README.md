# AI Beauty Photography · 美妆商业摄影导演 Skill（Codex）

> A Codex Skill that directs commercial beauty photography: it turns a beauty product and a business goal into a cast synthetic model, a campaign plan and shot-by-shot direction, then uses Codex's built-in image generation and checks the results. Model-led campaigns across all beauty categories, with product-only, texture and swatch shots when the task needs them.

## 它做什么

你给出一个美妆产品和商业目标（受众、品牌定位、投放渠道），Skill 像一位商业摄影导演那样工作：

1. **理解产品与任务**：把产品图可见的事实、品牌提供的主张和未知项分开，不编造功效、成分或色号表现。
2. **先给方向，再按产品选角**：开放需求先给 2–3 个差别大的方向，每个方向是一张图，写清真实地点与时刻、人物与构图，由你挑选；为选定方向具体定一位虚构的成年合成模特（年龄、发型、肤色、眼睛、一个辨识点），标准是目标顾客觉得非常美、想成为的人，每个系列换新人。同一系列内以第一张通过的人物图作为后续镜头的身份参考。
3. **策划 Campaign**：由商业任务决定需要几张图、每张承担什么作用，不套固定模板；需要时加入产品静物、质地或色卡镜头。
4. **写短提示词**：按一个模板只填空：真实地点与时刻及其自然光、模特、构图（留白取自场景本身——天、墙、暗部或柔和背景——按画幅放在侧边、上方或下方，给 logo 和广告语，不缩小妆效）、主打妆效、产品与无品牌包装；姿势、手、光的方向和镜头交给生图模型，除非需求明确要求。
5. **生成与检查**：先确认当前 Codex 宿主提供原生图像生成，再调用它生成（没有这项能力时只输出拍摄 brief 和提示词），逐张检查并如实报告；不重抽、不局部修补。

面向全美妆品类（唇妆、眼妆、底妆、护肤、美妆工具、香氛与身体护理等），按品类和产品决定镜头与动作。

## 它不做什么

- 不使用真人模特，不做真人身份迁移，不模仿真人或名人；只生成虚构的成年合成人物。
- 不修改真实产品的包装、Logo、标签，也不合成最终的产品图；不保证 SKU 文字和标签完全还原。
- 不保证跨镜头的人脸完全一致：同一系列以第一张通过的人物图作为身份参考，并在每张图上检查漂移。
- 不调用外部 API，不需要 API Key，只使用当前 Codex 宿主自带的图像能力。

## 安装

把 `ai-beauty-photography/` 目录放到 Codex 能读取 Skill 的位置，例如项目内的 `.agents/skills/ai-beauty-photography/`。具体目录以 Codex 当前文档为准。

## 用法示例

在 Codex 里直接描述任务即可，例如：

> 为一款蜜桃色腮红膏策划一组商业图，用于电商详情页和小红书，目标消费者是 25–35 岁女性，品牌定位轻熟、自然。

开放式的需求下，Skill 通常先给出 2–3 个有差异的创意方向；方向确定后选角、规划整组图片并逐张写短提示词，再生成和检查图片。

## 案例

先看全貌：[六个品类 × 12 个需求](examples/six-categories.md)，每个需求出 1 张、未挑选，12 张拼成一张图。

`examples/` 里还有四个从一句需求到成图的完整过程，方向、提示词与成图均为原样输出，每张只出 1 次、未挑选：

- [蜜桃色腮红膏 · 城市午后](examples/blush-cafe.md)（小红书首图 3:4）
- [身体精华油 · 赤陶暖夏](examples/body-oil-terracotta.md)（官网横幅 16:9）
- [哑光正红口红 · 午后画廊](examples/lipstick-gallery-series.md)（小红书 3:4，附产品照片，同一系列两张）
- [卸妆油 · 一个需求、三个方向、各 4 张](examples/cleansing-oil-three-directions.md)（附产品照片，电梯海报 3:4 + 电商首图 1:1 + 信息流 4:5 × 2，每个方向同一位模特）

前两例来自同一批 3 个需求，第 3 个（防晒乳，男模特）成图里包带的背法不成立，判为"凑合"，未收录。口红一例来自附产品照片的测试，同批另两个需求（精华液、卸妆油）的单张未收录，其中精华液持瓶的手别扭；卸妆油一例是之后用同一张产品照片另跑的完整套图。

## 当前证据（如实说明）

以下结论来自作者在开发中做的小样本出图测试（Codex 内置图像生成），样本很小，只供参考：

- **当前版本：**6 类（唇、眼、底妆、护肤、香氛、工具）× 2 个需求共 12 个，先给方向、取 Skill 自己推荐的方向各出 1 张：项目负责人判可用 10/12、6 类均有可用；凑合的两张是睫毛膏刷头结构不对、粉底瓶在画面里偏小。每个需求只出 1 张。同样 12 个需求不加载 Skill 对照时，忽略图中文字后画面质量差距不大，但 12 张里 11 张把广告语画进图里、模特几乎同一张脸；Skill 已证实的价值是交付规范（不写字、每张换模特、真实地点、按画幅留白、产品一定在画面里），而不是画面更好看；模特长相仍有重复，姿势多为把产品举在脸旁。
- **附上自己的产品照片：**口红、精华液、卸妆油各附一张无品牌产品照（图库棚拍，比手机随手拍干净），各出 1 张：3 张的产品外观（形状、颜色、瓶盖或泵头、比例）都和照片一致；项目负责人判可用 2 张，另 1 张持瓶的手别扭。
- **同一系列沿用同一位模特：**以一张已通过的图作身份参考，再出后续镜头 1 张，项目负责人判为同一个人；只有一个系列、一张后续镜头，样本很小。规划里的另一张嘴唇大特写被生图平台的输出审核拦截、没有产出——需要这类镜头时请留意。
- **上一版本（精简版）：**口红、眼线笔各 3 张，作者判为"可用的保底"，但偏棚拍感、同一需求几张雷同。
- **早期版本（规则更多）：**腮红膏、眼线笔的同条件盲评中，最佳图出自加载 Skill 的一组；但按"能否直接当商业广告用"复判，没有一张达到商业级，不能用的几乎都坏在手上。这些结论不适用于当前版本。
- **请逐张检查**手、手臂与产品的关系，以及包装上有没有类似真实品牌的标志，再决定是否使用。

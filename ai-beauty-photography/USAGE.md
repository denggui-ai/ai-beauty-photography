# AI Beauty Photography Skill — 使用说明

> 本文件只是简短说明；行为规则以同目录 `SKILL.md` 为准，两者冲突时以 `SKILL.md` 为准。

## 1. 这个 Skill 做什么

面向全美妆品类、以模特为主的商业广告摄影导演：理解产品与商业目标，从产品的妆效出发先给 2–3 个方向由用户挑，为虚构合成成年模特具体选角，按一个模板写出生图提示词（真实地点与时刻、构图与留白；姿势、光线方向、镜头交给生图模型），出图后按质检清单检查结果。它调用当前 Codex 宿主自带的图像生成能力，不包含独立图像模型。

## 2. 怎么用

在 Codex 会话里直接说需求即可，例如：

- “这是我的腮红膏，请你生成带模特的广告商业摄影作品。”（可附产品图，仅作产品外观参考）
- “为一瓶无品牌玻璃香水做一张纯静物广告主视觉，不要模特。”

不需要填表；只有缺少会改变商业任务的信息时，Skill 才会提问。

## 3. 边界

- 只生成虚构的合成成年模特；不使用真人模特，不索要个人模特照片，不做真人身份迁移或名人模仿。
- 产品图（如提供）只作外观参考；不抠图、不修 Logo 或标签、不重绘包装、不做最终商品合成，不保证 SKU 文字精确。
- 不编造功效、成分、持妆时长等未经提供的卖点。
- 参考图只引导模型，不锁定人脸、姿势或产品几何；结果须看图检查。
